# Visual Question Answering for Indian Cultural Heritage

A multimodal deep learning system that answers natural language questions about images of Indian monuments and cultural heritage sites.

## Project Overview

This project implements a Visual Question Answering (VQA) system combining:

- **Vision Encoder**: ResNet50 (pre-trained on ImageNet)
- **Language Encoder**: LSTM for question processing
- **Fusion Module**: Late fusion with concatenation
- **Custom Dataset**: 400+ images, 2000+ QA pairs

## Quick Start

### Installation

```powershell
# Clone repository
git clone https://github.com/sattam-das/indian-heritage-vqa.git
cd indian-heritage-vqa

# Create virtual environment
python -m venv venv
venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```
